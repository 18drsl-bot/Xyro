Backup loader

If the main loadstring ever fails to load or execute on your executor, use this one instead. It fetches the same source code through a hardened chain: GitHub API (never cached) → global CDN → cache-busted raw → GitHub Pages, with 3 attempts per mirror, byte-count sanity checks, and exact error reporting if every path fails.

loadstring(game:HttpGet("https://raw.githubusercontent.com/vertxxy-1/Xyro/main/loadstring.lua"))()

Both loaders run identical code — the backup just tries harder to fetch it. Prefer the main one day-to-day.
